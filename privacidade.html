Hermes — Política de privacidade

Astrontech · atualizada em 07/10/2026

Hermes é um assistente de uso interno operado pela Astrontech para Fábio Lopes. Ele não é oferecido ao público e só acessa contas Google que o próprio titular autorizou.

O que o Hermes acessa

  • Gmail: ler e organizar e-mails e enviar mensagens pedidas pelo titular.
  • Google Agenda: ler e criar eventos.
  • Drive, Docs e Planilhas: ler e editar arquivos indicados pelo titular.
  • Contatos: somente leitura.

Como os dados são usados e guardados

  • Os dados são usados apenas para executar tarefas pedidas pelo titular.
  • Os tokens de acesso ficam criptografados na máquina do titular, com acesso restrito ao usuário dele. Não há servidor da Astrontech guardando e-mails ou arquivos.
  • Nenhum dado é vendido, compartilhado com terceiros para publicidade ou usado para treinar modelos.
  • O uso de dados obtidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, inclusive os requisitos de Uso Limitado.

Como revogar

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions, removendo o app “Hermes”.
